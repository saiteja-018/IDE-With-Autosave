HTML ELEMENTS

  1. <html >: The root element that wraps the entire HTML document.
  2. <head >: Contains meta-information about the document, such as the title and links to external resources.
  3. <title >: Sets the title of the web page, displayed in the browser's title bar or tab.
  4. <meta >: Provides metadata about the HTML document, such as character encoding and author information.
  5. <link >: Defines relationships between the current document and external resources, like stylesheets.
  6. <script >: Embeds or references JavaScript code within the HTML document.
  7. <style>: Embeds or references CSS (Cascading Style Sheets) to control the presentation of the content.
  8. <body>: Contains the main content of the web page, including text, images, and other elements.
  9. <h1>, <h2>, <h3>, ... <h6>: Headings that define the structure and hierarchy of the content.
  10. <p>: Represents a paragraph of text.
  11. <a>: Defines hyperlinks to other web pages or resources.
  12. <img>: Embeds images in the document.
  13. <ul>: Creates an unordered (bulleted) list.
  14. <ol>: Creates an ordered (numbered) list.
  15. <li>: Represents list items within <ul> or <ol> lists.
  16. <div>: A generic container for grouping and styling elements.
  17. <span>: A generic inline container for styling text or other inline elements.
  18. <table>: Defines a table structure.
  19. <tr>: Represents a table row.
  20. <td>: Defines a table cell.
  21. <th>: Defines a table header cell.
  22. <form>: Creates a form for user input.
  23. <input>: Represents various form input types, such as text, password, and checkboxes.
  24. <button>: Creates a clickable button within a form.
  25. <textarea>: Defines a multiline text input area within a form.
  26. <select>: Creates a dropdown menu for selecting options within a form.
  27. <option>: Represents an option within a <select> element.
  28. <label>: Associates a label with a form element to improve accessibility.
  29. <fieldset>: Groups related form elements and adds styling and accessibility features.
  30. <legend>: Provides a caption or title for a <fieldset> element.
  31. <iframe>: Embeds an inline frame for displaying external content within a web page.
  32. <audio>: Embeds audio content, such as music or sound clips.
  33. <video>: Embeds video content for playback in a web page.
  34. <canvas>: Provides a blank canvas for rendering graphics and animations using JavaScript.
  35. <svg>: Defines scalable vector graphics for creating vector-based images and animations.
  36. <nav>: Represents a navigation section within a document.
  37. <header>: Represents a container for introductory content or a set of navigational links.
  38. <footer>: Represents a container for the footer section of a document.
  39. <aside>: Defines content that is tangentially related to the content around it.
  40. <section>: Represents a thematic grouping of content within a document.
  41. <article>: Represents a self-contained composition or article that can be independently distributed or reused.
  42. <main>: Specifies the main content of a document, excluding headers, footers, and sidebars.
  43. <time>: Represents a specific period in time or a range of time.
  44. <figure>: Groups media content (e.g., images) and their captions (e.g., <figcaption>).
  45. <figcaption>: Provides a caption or description for a <figure> element.
  46. <abbr>: Defines an abbreviation or acronym, optionally providing a full explanation.
  47. <address>: Specifies contact information for the author or owner of a document or article.
  48. <mark>: Highlights text for reference or emphasis, often displayed with a yellow background.
  49. <code>: Represents a fragment of computer code, typically displayed in a monospace font.
  50. <pre>: Represents preformatted text, maintaining whitespace and line breaks.
HTML Attributes:
  1. id: Provides a unique identifier for an element.
  2. class: Assigns one or more class names to an element for styling or JavaScript purposes.
  3. src: Specifies the source URL for external resources like images, scripts, or stylesheets.
  4. href: Defines the target URL for hyperlinks.
  5. alt: Provides alternative text for images for accessibility.
  6. style: Inline CSS styling for an element.
  7. width and height: Specifies the dimensions of an element like images and tables.
  8. colspan and rowspan: Defines how many columns or rows a table cell should span.
  9. placeholder: Sets a temporary text hint for input fields.
  10. disabled: Disables user interaction with an element.
  11. value: Specifies the default value for input elements.
  12. name: Associates a name with form elements for submission.
  13. required: Specifies that an input field must be filled out before submitting a form.
  14. checked: Sets the default state of a checkbox or radio button to checked.
  15. readonly: Makes an input field or textarea read-only.
  16. multiple: Allows selecting multiple options in a <select> element.
  17. min and max: Defines the minimum and maximum values for input elements with numerical values.
  18. step: Specifies the incremental step for numeric input elements.
  19. autofocus: Automatically focuses on an input field when the page loads.
  20. download: Specifies that a link should download a resource instead of navigating to it.
  21. target: Specifies where to open linked documents or resources (e.g., _blank for a new tab).
