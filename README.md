# IDE with Autosave

## Project Overview
This project is an interactive web-based application built with HTML, CSS, and JavaScript. It features an IDE-like environment with autosave functionality, designed to provide a seamless coding and learning experience directly in the browser.

## Features
- **Code Editor Environment:** Multiple HTML files provide structured learning pages (`learn.html`, `learn1.html`, `learn2.html`), including interactive content.
- **Autosave Functionality:** JavaScript (`fun.js`) manages autosave functionality, ensuring that user input/code is preserved automatically without manual saves.
- **User Authentication:** `sign.html` suggests a sign-in or user authentication interface, supporting personalized user sessions.
- **Theming and Styling:** `color.css` handles styling and theming, providing a visually appealing and consistent UI.
- **Logging and Debugging:** `log.html` is used for capturing logs or output messages, aiding in debugging and feedback.
- **Main Entry Point:** `main.html` serves as the primary launch page or dashboard of the application.

## Technologies Used
- HTML5 for structure and content.
- CSS3 for styling and responsive design.
- JavaScript (vanilla) for client-side interactivity and autosave logic.

## Getting Started
1. Clone the repository:
git clone https://github.com/saiteja-018/IDE-With-Autosave.git
2. Open `main.html` in a modern web browser to launch the application.
3. Explore the `learn.html` and related learning pages for demos and tutorials.
4. Use the autosave feature while editing code snippets or interactive content.

## Project Structure
- `main.html`: Main dashboard/home page.
- `learn.html`, `learn1.html`, `learn2.html`: Tutorial and learning content HTML files.
- `sign.html`: Authentication or sign-in page.
- `log.html`: Console or log output interface.
- `color.css`: Styling and theme file.
- `fun.js`: JavaScript logic including autosave and interactive behavior.
