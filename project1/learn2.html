  1. **Mouse Events:**
    • <element.onclick>: Executes code when an element is clicked.
    • <element.onmousedown>: Executes code when the mouse button is pressed down on an element.
    • <element.onmouseup>: Executes code when the mouse button is released on an element.
    • <element.onmousemove>: Executes code when the mouse pointer moves within an element.
    • <element.onmouseover>: Executes code when the mouse pointer enters an element.
    • <element.onmouseout>: Executes code when the mouse pointer leaves an element.
    • <element.onmouseenter>: Executes code when the mouse pointer enters an element (does not bubble).
    • <element.onmouseleave>: Executes code when the mouse pointer leaves an element (does not bubble).
    • <element.oncontextmenu>: Executes code when the right mouse button is clicked on an element.
  2. **Keyboard Events:**
    • <element.onkeydown>: Executes code when a key is pressed down while the element has focus.
    • <element.onkeyup>: Executes code when a key is released while the element has focus.
    • <element.onkeypress>: Executes code when a key is pressed and released while the element has focus.
  3. **Form Events:**
    • <element.onsubmit>: Executes code when a form is submitted.
    • <element.onreset>: Executes code when a form is reset.
    • <element.onchange>: Executes code when the value of an input element changes.
    • <element.oninput>: Executes code when the user interacts with an input element (e.g., typing in a text field).
  4. **Focus Events:**
    • <element.onfocus>: Executes code when an element receives focus.
    • <element.onblur>: Executes code when an element loses focus.
  5. **Window Events:**
    • <window.onload>: Executes code when the entire page (including all assets) has finished loading.
    • <window.onresize>: Executes code when the browser window is resized.
    • <window.onscroll>: Executes code when the user scrolls the page.
    • <window.onunload>: Executes code when the user leaves the page (e.g., closes the tab or browser).
  6. **Media Events:**
    • <element.onplay>: Executes code when media (e.g., audio or video) starts playing.
    • <element.onpause>: Executes code when media is paused.
    • <element.onended>: Executes code when media playback reaches the end.
    • <element.ontimeupdate>: Executes code as media playback progresses (e.g., updating a progress bar).
Certainly! Here's a list of common JavaScript alerts, confirms, and prompts that you can use to interact with users: JavaScript Dialogs:
  1. **Alert Dialog:**
    • alert(message): Displays a simple dialog box with a message and an "OK" button. Used for informational pop-ups.
  2. **Confirm Dialog:**
    • confirm(message): Displays a dialog box with a message, an "OK" button, and a "Cancel" button. Returns true if the user clicks "OK" and false if "Cancel" is clicked.
  3. **Prompt Dialog:**
    • prompt(message, defaultText): Displays a dialog box with a message, an input field, an "OK" button, and a "Cancel" button. Returns the text entered by the user or null if "Cancel" is clicked.
