CSS Properties

  1. color: Sets the text color.
  2. font-family: Defines the font for text.
  3. font-size: Sets the size of the font.
  4. font-weight: Specifies the thickness of characters in text.
  5. text-align: Aligns text horizontally (left, right, center, justify).
  6. text-decoration: Adds decorations to text (underline, overline, line-through).
  7. background-color: Sets the background color of an element.
  8. background-image: Specifies a background image.
  9. background-size: Controls the size of the background image.
  10. background-position: Sets the starting position of the background image.
  11. border: Creates a border around an element (width, style, color).
  12. margin: Sets the margin space outside the border.
  13. padding: Sets the padding space inside the border.
  14. width: Defines the width of an element.
  15. height: Defines the height of an element.
  16. display: Specifies how an element should be displayed (block, inline, inline-block, etc.).
  17. position: Defines the positioning method of an element (relative, absolute, fixed).
  18. top, right, bottom, left: Positions an element precisely within its container.
  19. float: Aligns an element to the left or right within its container.
  20. clear: Specifies which sides of an element floating elements should not be allowed.
  21. z-index: Controls the stacking order of positioned elements.
  22. overflow: Defines how content should behave when it overflows its container.
  23. box-sizing: Specifies how the total width and height of an element are calculated.
  24. cursor: Defines the mouse cursor appearance when hovering over an element.
  25. list-style-type: Sets the style of list item markers (disc, circle, decimal, etc.).
  26. text-transform: Controls the capitalization of text (uppercase, lowercase, capitalize).
  27. line-height: Sets the height of a line of text.
  28. letter-spacing: Adjusts the spacing between characters in text.
  29. text-shadow: Adds a shadow effect to text.
  30. box-shadow: Adds a shadow effect to an element.
  31. border-radius: Rounds the corners of an element.
  32. opacity: Controls the transparency of an element.
  33. transition: Creates smooth transitions for CSS properties.
  34. transform: Applies 2D or 3D transformations to an element.
  35. animation: Specifies animations for elements.
  36. @media: Defines media queries for responsive design.
CSS Selectors:
  1. Type selector: Selects elements of a specific type (e.g., p selects all paragraphs).
  2. Class selector: Selects elements with a specific class (e.g., .highlight selects all elements with class "highlight").
  3. ID selector: Selects a single element with a specific ID (e.g., #header selects the element with ID "header").
  4. Descendant selector: Selects elements that are descendants of a specific element (e.g., ul li selects all list items within unordered lists).
  5. Child selector: Selects elements that are direct children of a specific element (e.g., ul > li selects all list items that are immediate children of unordered lists).
  6. Universal selector: Selects all elements (e.g., * selects all elements).
  7. Attribute selector: Selects elements based on their attributes (e.g., [type="text"] selects all input elements with type="text").
  8. Pseudo-class selector: Selects elements based on their state or position (e.g., :hover selects elements when hovered over).
  9. Pseudo-element selector: Selects parts of an element (e.g., ::before selects the content before an element).
  10. content: Specifies generated content before or after an element using the ::before and ::after pseudo-elements.
  11. user-select: Controls whether an element can be selected or not by the user.
  12. outline: Sets the outline around an element (width, style, color).
  13. text-overflow: Defines what should happen when text overflows its containing element.
  14. white-space: Controls how whitespace inside an element is handled.
  15. word-wrap: Specifies how long words should be broken and wrapped to the next line.
  16. background-attachment: Sets whether a background image is fixed or scrolls with the content.
  17. background-repeat: Defines how a background image should repeat (repeat, repeat-x, repeat-y, no-repeat).
  18. background-clip: Determines the area of an element that is affected by the background properties.
  19. box-shadow: Adds a shadow effect to an element.
  20. box-sizing: Specifies how the total width and height of an element are calculated.
  21. text-transform: Controls the capitalization of text (uppercase, lowercase, capitalize).
  22. text-overflow: Specifies what should happen when text overflows its containing element.
  23. overflow-x and overflow-y: Defines the behavior of overflow in the horizontal and vertical directions.
  24. :nth-child(): Selects elements based on their position within a parent element.
  25. :not(): Selects elements that do not match a specified selector.
  26. :focus: Selects an element when it is focused.
  27. :first-child: Selects an element that is the first child of its parent.
  28. :last-child: Selects an element that is the last child of its parent.
  29. :first-of-type: Selects the first element of a specific type within its parent.
  30. :last-of-type: Selects the last element of a specific type within its parent.
  31. :nth-of-type(): Selects elements of a specific type based on their position within their parent.
  32. :enabled: Selects form elements that are enabled (not disabled).
  33. :disabled: Selects form elements that are disabled.
  34. :checked: Selects radio buttons or checkboxes that are checked.
  35. :before and :after: Pseudo-elements to insert content before or after an element.
